# Statistical design and interpretation

ANWG is the study's arrival-normalized weighted goodput endpoint. It divides the priority-weighted count of completed requests meeting their deadlines by the priority-weighted count of all arrivals. Dropped/uncompleted arrivals remain in the denominator. Stored `reward_*` values are ANWG. Metric projections also contain mean soft credit, weighted completion goodput (WCG), weighted mean tardiness (WMT), and weighted normalized tardiness (WNT). This package does not recompute these from withheld per-request trajectories; it recomputes paired differences and their aggregation from the saved endpoints.

For a trajectory comparison, delta = treatment − base for higher-is-better metrics. WMT/WNT differences are reversed for benefit orientation. For two substituted modules the interaction is `both − first − second + base`. Its sign describes departure from additivity, not necessarily a benefit. In particular, a positive interaction can mean subadditive degradation.

Controlled comparisons first average fixed intervention pairs within each workload instance, then bootstrap the 10 independently generated workload seeds per condition. Pairs sharing a workload are not independent units. Canonical inputs were serialized to ten decimals, so comparisons to full-precision historical summaries allow 2e-9 absolute error. This is serialization tolerance, not scientific effect tolerance. Per-pair intervals are pointwise. The historical FDR threshold was q=0.1, not 0.05. Reproduction preserves the 17 priority findings and 0 prefill findings under the plus-one tail sensitivity. Historical zero bootstrap tail frequencies are finite-sample counts, not exact zero probabilities. With B=2,000, the documented two-sided plus-one sensitivity has minimum 2/2,001; it is not a new exact randomization test or a new significance claim.

Erasure cells contain the sums across three repeated simulation seeds for each pair/window. Numerator is erased actionable disagreements; denominator is actionable disagreements. The pooled estimand divides summed counts. The equal-positive-cell mean averages only fractions with denominator >0. Zero-denominator cells are retained and counted, never set to rate zero. A draw with no actionable disagreements is undefined and reported. Resample whole windows within seven fixed source strata, preserving all pairs and repeated seeds. Primary B=10,000; separate unstratified and source-hierarchical sensitivities remain available. Local results cover three selected pairs out of 38 eligible pairs, not all pairs. Frozen eligibility count 38 is an audited inventory fact, not reconstructed from three selected pairs.

Replay correlations give equal weight to 63 window-rate observations, but bootstrap 21 upstream windows (three per fixed source), retaining all three rates within each selected window. Source means are recomputed on each draw for centered correlation. The early/middle/late windows were deterministic selections; reported percentile ranges are conditional sensitivity under exchangeability, not calibrated production-population intervals. Undefined draws are omitted and counted. Diagnostic ratios were stored; original per-window decision denominators were not fully serialized, so event-weighted inference is unavailable. The historical 72 requests per instance supports a certified count of 1,512 distinct source records, but identity reconstruction is intentionally unavailable from these projections.

KV summaries use ten shared held-out seed streams; each stream retains the complete fixed design of conditions/pairs. Six declared-slot pairs, all thirteen historical mixed rows, and the single unflagged pair are separate populations. Each population's estimate and interval use that same population. All are exploratory. Ten compatibility flags remain five INVALID native-Scorpio interpretations and five INCONCLUSIVE reserve interventions. Runtime acceptance is not semantic validation.

Metric categories use tolerance 1e-12 after orienting differences toward benefit: mixed positive/negative values are sign-sensitive; otherwise a mixture of nonzero and near-zero values is detection-sensitive; all near-zero values are all-near-null. This is a deterministic numerical description, not significance, equivalence or practical benefit. The panel contains four overlapping campaign families; do not count those rows as independent test groups.

Seeds are fixed numerical controlled seeds or SHA-256-derived seeds for post-hoc analyses. Python process-randomized `hash()` is not used. Quantiles use linear interpolation. The released statistical adapters preserve Stage 2A/2A2 definitions; no historical simulation was rerun.
