# Exclusions and scope

| Material | Reason |
|---|---|
| Azure/BurstGPT/Mooncake raw records and reconstructive request/state sequences | Outside this outcome package; Mooncake trace-specific redistribution grant unresolved, and exact historical filtered BurstGPT bytes unavailable. A code license does not grant a data license. |
| Source row intervals, production IDs, token lengths, arrivals, cache identifiers and exact real-engine vectors | Could reconstruct protected inputs or expose metadata; vectors cannot be used for public pairing verification. |
| Private repository history, manuscripts/PDFs, editorial correspondence and author communications | Not authorized for this public research package; no entire private Git repository is transferred. |
| Raw experiment logs, hostnames, local/cluster paths and credential-bearing configuration | Unnecessary private operational metadata; only allowlisted statistical fields are exported. |
| Original trajectory-erasure raw files | Approximately10.3GB of trace-derived states. Only per-pair/window classification counts are public. Original local stage samples are also excluded. |
| Prospective raw outputs and archived Parquet | Mixed output fields are excluded. Public per-seed decision counts are enough for rates and source-stratified inference. |
| Historical predictions, missing original probes and seed archive | Not recovered; frozen scores and assertions receive no independent reconstruction credit. |
| Model weights, third-party implementations and publisher assets | Not needed or licensed by this release; dependencies retain upstream terms. |

Each shipped file is reviewed in `provenance/public_file_audit.csv`. Content hashes cover every package file except the hash manifest itself. File-level scans and allowlisted schemas are a scoped audit, not proof of absence of every conceivable identifying inference. Original synthetic pilot fixtures retain their own request/state fields because they are project-created research inputs. SHA-256 result fingerprints are provenance checksums, not trace cache identifiers.

Historical real-engine summaries are independently distributable project-generated measurements. They are presented as historically observed arithmetic, not independently verified paired causal estimates. Recorded input mismatch flags can be counted but cannot be independently recomputed without excluded or unavailable vectors. Fixed trace hashes, seed flags and request counts do not resolve this limitation.
