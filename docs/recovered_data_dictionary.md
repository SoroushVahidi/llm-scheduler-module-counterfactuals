# Recovered observations and statistical definitions

All new JSON observation tables are in `data/recovered/`. Source paths, selected field lists and SHA-256s are in `provenance/recovered_sources.json`; the additional raw hash lists identify excluded saved files, not public downloadable inputs. Containing commits and execution commits are distinct. Files retrieved outside Git have no invented containing commit. Original scientific outputs are not regenerated.

| Table | Unit and columns | Analysis |
|---|---|---|
| priority_probes | 30 base workload probes, ten per condition; config_id, cell_id, seed, n_decisions, candidate_set_ge2_fraction, priority_rank_disagreement_fraction | Equal-workload means; these are distinct from paired-trajectory diagnostics |
| fairness | Fixed fairness interventions within config_id/cell_id and seed; reward_base/reward_intervention, saved delta_anwg, intervention_id/module_type | Check endpoint differences within 2e-9; average interventions within each of five active workload instances, then bootstrap instances |
| heldout_singles | config_id, cell_id, family, kv_pressure_index, seed, intervention_id, module_type, paired rewards, delta_anwg/abs_delta_anwg, delta_num_slo_violated | 45 workload configs overall. Average dependent interventions within config before inference; pressure 0/1/2 is a design level |
| heldout_pairwise | Five config/seed four-arm observations; pairwise_id, base/first/second/both_reward, interaction | Both − first − second + base; sign stability compares the five seed contrasts to their mean |
| heldout_divergence | Fixed intervention within config/seed; module_type, decision_divergence_rate, fraction_requests_completion_time_changed, median_abs_completion_time_diff | Aggregate dependent comparisons within workload; time differences in seconds |
| heldout_priority_probes | Config/cell/seed, n_decisions and candidate/rank/top-choice/potential-divergence/promotion fractions | Join by config_id, correlate over 20 priority contexts including interaction contexts |
| heldout_prefill_probes | Config/cell/seed, n_decisions, pressure_ge_threshold_fraction, prefill_candidate_filter_disagreement_fraction, prefill_action_divergence_fraction | Join by config_id; five workloads per prefill cell |

| prospective_seed_counts | 2,100 rows: 140 source windows × 3 rates × 5 seeds; config/source/window/rate/seed keys and seven count fields | Recompute ratios, average five seed ratios per cell, select 1x for primary N=140; twenty windows/source, four source families |
| local_stage_counts | 504 seed × pair × window cells; config_id/pair_id/seed, local_actionable/local_final_divergence/local_overrides/unknown_ambiguous, cause_counts | Counts retained per seed; pool for descriptive taxonomy only, never event-level confidence intervals |
| trajectory_stage_counts | 168 pair-window groups; config_id/pair_id, three seeds, n_decision_records, counts | Aggregate stored actionable/final-divergent labels and cause labels; no events, times, input state or request IDs exported |

Prospective counts: n_decisions is the denominator of n_structural_ge2, n_actionable and n_final_action_divergent. n_actionable_and_final_divergent plus n_actionable_but_final_same equals n_actionable. Conditional actionability divides by n_structural_ge2; override rate divides n_actionable_but_final_same by n_actionable. Undefined 0/0 is missing, not zero. Seed means skip missing ratios as in the historical analyzer. Primary bootstrap stratifies the 140 windows within sorted source_family blocks (Azure2023, Azure2024, BurstGPT, Mooncake), B=2,000, NumPy default_rng seed4108260827; resample all correlated columns together. Linear 2.5/97.5 percentiles give the interval. Per-source correlations use 20 1x windows; source-centered correlations center within families. Rates are never pooled as independent primary observations.

Standalone fairness uses B=2,000, seed20270225. Held-out inference uses B=2,000, seed3108260827. Controlled priority and prefill use seeds1231191560 and1827463921. Bootstrap percentile intervals resample workload instances; the historical sign-tail p is twice the opposing bootstrap tail including zero. This differs from the finite-tail plus-one sensitivity already documented for the baseline. Permutation tests shuffle pooled instance values with a fresh copy per draw; hits start at one and divide by B+1. BH adjustment uses the declared families, not a new pooled testing family: held-out four primary tests; controlled 28 or4 singles within a condition, two cross-condition contrasts, and the separate interaction. Threshold comparisons use strict q<.05 or q<.10.

`analysis/historical_statistics.py` contains only inspected statistical functions extracted from original project code; imports cannot launch simulations. Rounded canonical endpoints/deltas are checked within absolute 2e-9, with no relative tolerance; integer counts must agree exactly. Prospective count-derived rates were independently compared with all 420 archived Parquet cells at absolute 1e-14. That Parquet and raw mixed-output files remain excluded.

Historical erasure quartiles select sorted[floor(q*(n−1))], separately from the usual median; 72 positive pair-window cells yield 96.6667% and99.7849%. The 96 zero-denominator cells are excluded from ratio summaries, not interpreted as zero erasure. The private historical source was last changed at commit62ec36c745ef2eb09a837d5fdc99c134b5736d43; `analysis/historical_quartile.py` exports the exact function. No quartile method was chosen by outcome matching.

`NaN` in historical JSON references and computed held-out descriptive relationships means an undefined correlation, never numerical evidence. Python's JSON reader accepts these historical records. Do not use them as strict RFC-8259 interchange without converting undefined values to null.
